# Day 3 creator profile backend

Day 3 now includes server-side validation for the user profile, profile photo URL, genres, skills, creative tags, availability and collaboration preferences. Existing GET /api/me and PUT /api/me remain compatible. GET /api/creators supports query, genre, skill, profession, availability, paging and limits (up to 50). GET /api/creators/:id supports an individual creator page. Public profile serialization excludes email, role and password hashes. Portfolio add/delete and PATCH /api/me/portfolio/:id support creator-owned samples. The frontend shows real profile photos by HTTPS URL and profile completeness. Photos are external URLs, not uploaded to the server. Authentication and project/MCCA routes are not changed. Tests run with npm test in server.

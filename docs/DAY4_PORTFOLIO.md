# Day 4. Music portfolio and showcase

Track links remain hosted at their original providers. No paid media storage or API keys. Portfolio metadata includes track title, URL, genre, tags, credits, short description and release year. Owner may add, edit, delete and select one featured sample. Frontend offers explicit-click embeds for Spotify, YouTube and SoundCloud from validated provider URLs. Unknown services remain ordinary links. Embeds load third-party scripts only when the visitor elects to preview. Creator profiles show titles and featured tags. Existing samples remain compatible.

Run server tests with `npm test` and frontend media tests with `node --test src/media.test.js`. The deployed API requires authenticated ownership for mutations.

MusicLink keeps the practical side in one place, so artists spend less time remembering tasks and more time making music.

Software engineering × music.

MusicLink started as a personal project by Nova, a software engineering student and independent artist. It explores how simple software tools support the independent music workflow. It is free, browser based and designed to grow with artist feedback.
